# Portrait Facile

Portrait Facile transforme une photo de référence en guide de construction pour dessiner un portrait.

## Fonctionnalités

- Import local JPG, PNG et WebP
- Rig paramétrique avec vues face, trois-quarts et profil
- Méthodes Canonique, Loomis, Reilly et Asaro
- Grille, repères hiérarchisés, opacité et zoom
- Ajustement manuel des repères
- Analyse faciale locale avec MediaPipe
- Projets, sauvegardes JSON et export PNG
- Manifest PWA et fonctionnement hors ligne du shell de l’application

Les images restent dans le navigateur. Aucune image n’est envoyée à un serveur.

## Développement

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
npm run preview
```
